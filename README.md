# DMZ Tracker

Static DMZ upgrades tracker for GitHub Pages.

## Site layout

- Published site files live in `docs/`.
- Helper tooling lives in `scripts/` and is not part of the GitHub Pages output.
- Local progress is stored only in the browser via `localStorage`.

## GitHub Pages

Configure GitHub Pages to publish from:

- Branch: `main`
- Folder: `/docs`

## Local use

Open `docs/index.html` in a browser for a direct-file preview.
